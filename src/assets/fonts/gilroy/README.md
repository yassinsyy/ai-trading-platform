# Gilroy Font Files

This directory should contain the Gilroy font files in WOFF2 format:

- Gilroy-Thin.woff2
- Gilroy-UltraLight.woff2
- Gilroy-Light.woff2
- Gilroy-Regular.woff2
- Gilroy-Medium.woff2
- Gilroy-SemiBold.woff2
- Gilroy-Bold.woff2
- Gilroy-ExtraBold.woff2
- Gilroy-Black.woff2

Please add these font files to this directory for the Gilroy font family to work properly.

The font-face declarations are already configured in `src/index.css`.
